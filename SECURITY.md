# Security Policy

ChemAI Recipes includes configuration guidance and links to third-party software.

- Never commit real API keys, tokens, credentials, cookies, or private endpoints.
- Prefer official releases, registries, documentation, and upstream repositories.
- Avoid opaque binary downloads and destructive shell commands.
- Community commands should be manually reviewed before merge.
- Users should review upstream security and data-processing terms.

Technical setup success does not establish scientific, regulatory, clinical, or safety validity.
