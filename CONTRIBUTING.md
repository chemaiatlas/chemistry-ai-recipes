# Contributing to ChemAI Recipes

Contributions are welcome for broken instructions, version updates, compatibility reports, troubleshooting improvements, and new Recipe proposals.

## Requirements

1. A Recipe must solve a clearly defined chemistry-related task.
2. Commands and downloads must point to official or verifiable upstream sources.
3. AI-generated combinations are not accepted without manual technical review.
4. Technical verification must not be described as scientific validation.
5. Never commit credentials, API keys, private datasets, proprietary structures, or other sensitive information.
6. Paid dependencies, cloud processing, and meaningful privacy implications must be disclosed.
7. Do not update `last_tested` unless the Recipe was actually re-tested.

For a new Recipe, open a Recipe Request issue before preparing a full pull request.
